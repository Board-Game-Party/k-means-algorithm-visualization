Lloyd's Algorithm
1. Initial: pick K points as the initial centroids 2. Repeat: 3.   Assign: attach every point to its nearest centroid 4.   Update: recompute each centroid = mean of its cluster 5. Until: the centroids stop moving
Goal: minimize cost(C) = Σi Σx∈Ci dist(x, ci)
This page reports it as SSE (sum of squared distances), which never increases from one iteration to the next.

Limitations of K-means▾
  • Clusters of unequal size → try “Different sizes”
  • Clusters of unequal density → try “Different densities”
  • Non-globular shapes → try “concentric rings”
  • Outliers drag centroids off target → try “Outliers”
  • K itself must be chosen up front. The algorithm only requires 1 ≤ K ≤ N — there is no fixed upper number, but you cannot have more clusters than data points.
  • SSE always falls as K rises, and reaches 0 at K = N (every point its own centroid), so a low SSE alone never proves a good K.
  • First remedy: use a K larger than the true number of groups, then merge the pieces afterwards.
The initialization problem▾
  • Initial centroids are usually random, so every run lands somewhere different (press Reset → Initialize a few times).
  • Remedy 1: run it many times and keep the lowest-error result → the Best Centroids button.
  • Remedy 2: start from points that are as far apart as possible → the Farthest-first mode.
The same thing in scikit-learn▾ 
from sklearn.cluster import KMeans
import numpy as np

X = np.array([[1,2],[1,4],[1,0],
              [4,2],[4,4],[4,0]])

km = KMeans(n_clusters=2, random_state=0).fit(X)
km.labels_          # [0 0 0 1 1 1]
km.cluster_centers_ # [[1. 2.] [4. 2.]]
