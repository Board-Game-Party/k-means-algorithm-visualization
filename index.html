Lloyd's Algorithm
1. Initial: เลือก K จุดเป็น initial centroids 2. Repeat: 3.   Assign: จับทุกจุดเข้า centroid ที่ใกล้ที่สุด 4.   Update: คำนวณ centroid ใหม่ = ค่าเฉลี่ยของกลุ่ม 5. Until: centroids ไม่ขยับอีก
เป้าหมาย: minimize cost(C) = Σi Σx∈Ci dist(x, ci)
หน้านี้แสดงค่าแบบ SSE (ผลรวมระยะทางยกกำลังสอง) ซึ่งลดลงเสมอทุกรอบจนลู่เข้า

ข้อจำกัดของ K-means▾
  • คลัสเตอร์มีขนาดต่างกัน → ลอง “Different sizes”
  • คลัสเตอร์มีความหนาแน่นต่างกัน → ลอง “Different densities”
  • คลัสเตอร์ไม่เป็นทรงกลม (non-globular) → ลอง “วงแหวนซ้อนกัน”
  • ข้อมูลมี outliers ดึง centroid ให้เพี้ยน → ลอง “Outliers”
  • ทางแก้เบื้องต้น: เพิ่มจำนวน K ให้มากกว่ากลุ่มจริง แล้วค่อยรวมชิ้นส่วนเข้าด้วยกันภายหลัง
ปัญหา Initialization▾
  • initial centroids มักถูกสุ่ม ทำให้ผลลัพธ์ต่างกันทุกครั้งที่รัน (ลองกด Reset → Initialize ซ้ำหลายรอบ)
  • ทางแก้ 1: รันหลายครั้งแล้วเลือกผลที่ error ต่ำสุด → ปุ่ม Best of 10 runs
  • ทางแก้ 2: เลือกจุดตั้งต้นที่ห่างกันมากที่สุด → โหมด Farthest-first
เทียบกับ scikit-learn▾ 
from sklearn.cluster import KMeans
import numpy as np

X = np.array([[1,2],[1,4],[1,0],
              [4,2],[4,4],[4,0]])

km = KMeans(n_clusters=2, random_state=0).fit(X)
km.labels_          # [0 0 0 1 1 1]
km.cluster_centers_ # [[1. 2.] [4. 2.]]
